## Short description (50 words)

## Long description (150-300 words)

dbdiagramr converts PostgreSQL schemas into interactive entity-relationship diagrams. Two ways to use: paste CREATE TABLE statements for an instant preview, or connect to a live database by pasting a connection string from Supabase, Neon, Railway, or any managed PostgreSQL provider.

Features:
- Paste SQL mode: paste CREATE TABLE statements, see a live ER diagram as you type. No server needed.
- Connect mode: paste a PostgreSQL connection string, introspect your live database schema.
- Interactive diagram: pan, zoom, hover to trace foreign key relationships.
- Search: find tables, columns, and types instantly.
- Export: PNG, SVG, or shareable link.
- Sample schemas: ecommerce, Supabase auth, and more to get started instantly.
- File upload: drag and drop .sql files.
- Free: 5 diagrams/month, no credit card required. Pro: $8/month for unlimited.
- Private: connection strings are never stored, schemas are discarded immediately.
- Open source: built with Next.js, TypeScript, and React Flow.

Unlike desktop tools (DbSchema, pgModeler, DBeaver), dbdiagramr runs entirely in your browser with no installation. Unlike code-first tools (dbdiagram.io), it works from a live database connection, not hand-written schema code.
