**Product Name:** dbdiagramr

**Website:** https://www.dbdiagramr.space

**Category:** Database Tools, Developer Tools

**Description:**
dbdiagramr is a free, open-source PostgreSQL ER diagram generator. Paste your SQL or connect to a live database to visualize your schema instantly. No account required. Supports drag-and-drop, file upload, and SVG/PNG export. Built with Next.js and React Flow.

**Features:**
- Paste SQL for instant ER diagram
- Connect to live PostgreSQL database
- File upload and drag-and-drop
- Search tables and columns
- Export SVG/PNG
- Live preview
- No account required

**Pricing:** Free (open-source)

**Why Free Alternative:**
dbdiagramr is completely free with no signup required. Unlike dbdiagram.io which has usage limits, dbdiagramr offers unlimited diagram generation. Open-source and privacy-first -- your SQL never leaves your browser.
